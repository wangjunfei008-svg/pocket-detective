> 所有文件读取均使用**相对路径**（`data/scenario.json`、`assets/style.css`），符合创空间规范。

## 🧠 算力双模自适应架构 / Dual-Mode Compute

`engine/llm_client.py` 按优先级自动选择后端，**任何一级失败都静默降级，永不抛异常**：

```
①  ⚡ DGX Spark 本地端侧     http://localhost:8000/v1  (OpenAI 兼容)
     ↓ 探测失败
②  ☁️ 魔搭云端 Qwen          MODELSCOPE_API_TOKEN / DASHSCOPE_API_KEY
     ↓ 无密钥 / 调用失败
③  🎭 内置童趣智能 Mock 剧本  零依赖离线剧本，保证可通关
```

| 模式 | 触发条件 | 说明 |
|---|---|---|
| **DGX Spark 端侧** | 本地 8000 端口有 OpenAI 兼容服务 | 对话**零数据外泄**，全部留在本机；界面标注端侧极速与隐私特性 |
| **魔搭云端** | 检测到 `MODELSCOPE_API_TOKEN` / `DASHSCOPE_API_KEY`，或侧边栏手填 Key | 走 Qwen 兼容端点；`sk-` 开头的 Key 自动路由到 DashScope |
| **童趣 Mock** | 以上都不可用，或侧边栏手动选择 | 关键词驱动的童趣剧本，会按心虚度改变语气，同样能通关 |

- 侧边栏「⚙️ 算力双模自适应」面板可切换模式、手填 Key、改端点与模型名、一键重新探测。
- 服务探测带 30 秒 TTL 缓存，不会每次交互都联网。
- 环境变量：`DGX_SPARK_BASE_URL`、`DGX_SPARK_MODEL`、`MODELSCOPE_API_TOKEN`、`DASHSCOPE_API_KEY`、`POCKET_DETECTIVE_FORCE_MOCK=1`。

### 启动 DGX Spark 本地服务示例

```bash
# 在 DGX Spark 上（示例，按你的推理框架调整）
python -m vllm.entrypoints.openai.api_server \
  --model Qwen/Qwen3-32B --port 8000 --max-model-len 8192
```

启动后在侧边栏选「⚡ DGX Spark 本地端侧推理」→ 点「🔁 重新探测算力」，状态灯变绿即接入成功。

## 🛡️ 儿童安全设计 / Child Safety

这是本项目**优先级最高**的设计约束，写死在代码里而不是文档里：

- **内容红线进 prompt**：`agents/characters.py` 的 `CHILD_SAFETY_RULES` 禁止恐怖、血腥、暴力、武器、恋爱、赌博、烟酒、政治宗教内容；限制回复长度；禁止角色自称 AI。
- **反派不是坏人**：三位嫌疑人只是「撒了小谎的孩子和老爷爷」，结局全部被原谅，不制造恐惧与对立。
- **零个人信息收集**：昵称只存在浏览器会话里，不上传、不落盘；无广告、无内购、无外链跳转、无埋点。
- **实验安全提示常驻**：每个科学知识点都带「请老师/家长陪同」「不要品尝」「碘伏会染色」「绝不用激光笔照眼睛」。
- **AI 不直接给答案**：鸡飞飞的系统提示词明确「最多给两步提示，绝不直接说出凶手」。
- **本地启动默认只监听 127.0.0.1**，需要教室平板访问时再显式 `HOST=0.0.0.0`。

├── data/
│   └── scenario.json           # 案情、线索网、科学知识点、结案判定、通关文案
├── assets/
│   ├── avatars.py              # 内置全套儿童绘本风 SVG 卡通立绘

## 🔬 三个科学知识点 / Science Takeaways

| 知识点 | 童趣解释 | 游戏内实验 | 家庭延伸 |
|---|---|---|---|
| 🍚 **淀粉遇碘变蓝紫** | 米汤里藏着看不见的「淀粉小弹簧」，碘钻进去就变蓝紫 | 碘伏棉签涂无字纸条 | 碘伏滴米饭变蓝紫，滴白糖水不变色 |
| 🌈 **光的折射与全反射** | 光进水里会拐弯；角度够斜就整个弹回来，像照镜子 | 手电筒斜照水槽玻璃 | 水杯里的吸管「断」了；光纤、海市蜃楼 |
| 🧂 **浓盐水密度大浮力大** | 水喝了很多盐之后「更有力气」托东西 | 盐袋 + 水槽复现浮蛋 | 死海漂着看书；清水沉、盐水浮的葡萄实验 |

`data/scenario.json` 里每个知识点都同时提供 `kid_explanation`（给孩子）、`adult_note`（斯涅尔定律 / F=ρgV / 淀粉-碘包合物，给老师家长）与 `experiment_steps`。

## ❓ 常见问题 / FAQ

**Q：不填 API Key 能玩吗？**
能。自动进入内置童趣剧本模式，三个实验、招供、通关勋章全部正常，评审可直接体验完整剧情。

**Q：怎么确认走的是 DGX Spark 本地算力？**
侧边栏展开「⚙️ 算力双模自适应」，状态灯显示「⚡ NVIDIA DGX Spark 端侧推理」并给出模型名、端点与延迟毫秒数。

**Q：想改案情 / 加一个新案件？**
编辑 `data/scenario.json`：新增嫌疑人、话题关键词、`guilt_delta`、`experiment`、科学知识点即可，无需改代码。文件损坏时会自动回落到内置兜底案情，不会白屏。

**Q：道具用错了会怎样？**
角色会童趣地吐槽（「这个玩意儿对爷爷的盐巴可不管用喽」），不扣分、不惩罚，鼓励继续尝试。

**Q：支持移动端吗？**
支持，CSS 已做响应式适配，适合平板在课堂或家里使用。
